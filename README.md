# 🚀 Custom C++ TDD Framework

Привет! Это мой учебный проект - собственный легковесный фреймворк для тестирования на языке C++. 

За основу я взял первую часть крутой книги **"Test-Driven Development with C++" (Abdul Wahid Tanner, 2022)** и пошагово реализовал модульную архитектуру с 1 по 8 главу.

## 🔥 Что умеет этот фреймворк?
* **Создавать тест-кейсы**: Каждый тест изолирован в своем классе (спасибо ООП).
* **Группировать тесты**: Можно собирать тесты в наборы (*Test Suites*) по темам.
* **Ловить баги за руку**: Кастомный макрос проверки точно знает, в каком файле и на какой строчке упал ассерт.
* **Не падать при критических ошибках**: Если тестируемый код выбросит шальное исключение, фреймворк аккуратно поймает его, запишет статус `ERROR` и пойдет тестировать дальше.
* **Делать уборку**: Поддерживает функции `setup()` и `teardown()` для подготовки окружения перед каждым тестом.
* **Красиво отчитываться**: В конце выводит в консоль аккуратную табличку с итогами.

## 📁 Структура проекта (строго по книге)
Проект аккуратно разделен на заголовочные файлы (`.hpp`) и файлы реализации (`.cpp`):
* `TestCase` — сердце фреймворка, запускает тесты и изолирует ошибки.
* `TestSuite` — коробка для сбора и массового запуска тестов.
* `Verify` — тот самый макрос проверки условий `REQ_TRUE`.
* `AssertionException` — умное исключение, запоминающее место сбоя.
* `TestResult` & `TestStatus` — карточки результатов.
* `ConsoleReporter` — наш консольный художник-оформитель.

## 🛠️ Как это собрать и запустить?

Проект настроен на сборку через **CMake** и компилятор **g++ (MinGW)**.

1. Откройте терминал в папке проекта.
2. Скомпилируйте код одной командой (с флагами статической сборки, чтобы не просить лишние `.dll`):
   ```bash
   g++ -fdiagnostics-color=always -g main.cpp AssertionException.cpp Verify.cpp TestResult.cpp TestCase.cpp TestSuite.cpp ConsoleReporter.cpp -static -static-libgcc -static-libstdc++ -o main.exe
   ```
3. Запустите готовый тест:
   ```bash
   ./main.exe
   ```

В `main.cpp` уже заложен пример теста для проверки функции возведения в квадрат. Вы увидите красивый отчет прямо в консоли!
